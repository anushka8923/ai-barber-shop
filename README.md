\# AI Barber Shop



A full-stack appointment booking system for a barber shop, built with Next.js, Express, and MongoDB.



\## Features

\- Customer booking system with real-time slot availability

\- Admin dashboard for managing barbers, services, and slots

\- AI chatbot for customer support



\## Tech Stack

\- Frontend: Next.js, React, Tailwind CSS

\- Backend: Express.js, MongoDB, Socket.io

\- AI: Groq API
